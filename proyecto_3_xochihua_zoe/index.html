CSS3

tercera y más amplia evolución del lenguaje de hojas de estilo en cascada (Cascading Style Sheets)

CSS3

utilizado para diseñar y dar formato visual a páginas web estructuradas con HTML.

CSS3

Permite que el HTML maneje la estructura o esqueleto de la página, mientras que CSS controla la apariencia visual (colores, fuentes y distribución)

CSS3

Utiliza herramientas como las media queries para adaptar los sitios web a diferentes tamaños de pantalla (computadoras, tabletas y teléfonos móviles)

Módulos independientes

A diferencia de versiones anteriores, CSS3 se dividió en módulos (como selectores, caja modelo, flexbox y rejillas), lo que facilitó su actualización por partes.
